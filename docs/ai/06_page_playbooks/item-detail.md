# 페이지 플레이북 — 물품 상세 (`src/app/item/[id].tsx`)

관련 요청문: REQ-F-005, REQ-F-009(관리자 QR)

## 구성

- 이름·상태 배지·설명.
- 신청 영역은 상태에 따라 하나만 보인다.
  - 본인 대기 신청 있음 → "내 신청 대기" + 내 대여로 이동
  - 대여 가능 → `DueDatePicker`(기본 3일 후, 오늘 이전 불가) + "대여 신청"
  - 대여 중 / 사용 중지 → 안내 문구
- 관리자에게만 `ItemQr`(값 `billim://item/<id>`)과 "물품 정보 수정".

## 알아야 할 것

- 신청 성공 후 `router.navigate('/my')`. 실패하면 `SubmitButton`이 문구를 보여주고, `useApiMutation`이
  목록·상세를 다시 불러와 최신 상태(예: 그사이 대여 중으로 바뀜)를 보여준다.
- 날짜는 `todayInSeoul()` 기준. 서버도 같은 기준으로 다시 검증한다.
