# 페이지 플레이북 — 내 대여 (`src/app/(tabs)/my.tsx`)

관련 요청문: REQ-F-007, REQ-F-008, REQ-F-011

## 구성

세 구역을 한 스크롤에 둔다.

1. **대여 중** — 열린 대여. 기한 경과면 "기한 경과" 배지. `active`면 "반납 요청", `return_requested`면 안내 문구.
2. **승인 대기** — 대기 신청마다 "신청 취소".
3. **지난 신청** — 승인·거절·취소된 신청과 처리 시각, 거절 사유.

## 알아야 할 것

- 반납 완료는 관리자만 한다. 이 화면에 반납 완료 버튼을 두지 말 것.
- 취소가 `ALREADY_PROCESSED`로 실패하면(그사이 관리자가 처리) 문구를 보여주고 목록을 다시 불러온다.
