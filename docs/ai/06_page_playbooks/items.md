# 페이지 플레이북 — 물품 목록 (`src/app/(tabs)/index.tsx`)

관련 요청문: REQ-F-002

## 구성

- 검색창(이름, 대소문자 무시) + 상태 필터 칩(전체·대여 가능·대여 중·사용 중지) + "QR 스캔" 버튼.
- 목록은 `useItems({ query, status })`. `placeholderData: keepPreviousData`로 입력 중 깜빡임을 막는다.
- 각 행: 이름·설명·상태 배지, 본인 대기 신청이 있으면 "내 신청 대기" 배지. 행 접근성 이름에 상태를 포함한다.
- `StateView`로 로딩·오류(다시 시도)·빈 목록을 처리. 검색·필터가 있으면 "조건에 맞는 물품이 없습니다."
- 당겨서 새로고침(`RefreshControl`).

## 알아야 할 것

- 상태는 서버가 계산해 준 값(`Item.status`)을 그대로 쓴다. 화면에서 다시 계산하지 말 것.
